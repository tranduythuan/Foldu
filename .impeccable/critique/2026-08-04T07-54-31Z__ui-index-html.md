## Design Specificity Verdict
Highly authored (hand-drawn SVG flags, hand-computed contrast, plain-Vietnamese copy, virtual list). Detector: **0 findings, exit 0**; app shell renders in plain browser, zero console errors. The "too convoluted" complaint is an information-architecture/cognitive-load problem concentrated in 4 hotspots, not a mechanical design-quality problem.

## Cognitive Load
Checklist: 4/8 FAIL (single focus, chunking ≤4, one-decision-at-a-time on screen 3 open, working-memory bridges). Screen 3 with "Tự chỉnh chi tiết" open ≈ 35–45 controls / ~15 decisions in a 396px column. Decision points >4 visible options: preset grid (8, none preselected), time-format dropdown (12), rename pieces (5+), step-4 filters (5), criteria modal (searchable catalog).

Memory bridges: (1) scope.deep.desc forward-references "bước 3"; (2) safety toggles toast "Cần quét lại" with no rescan button; (3) ReportOnly mode but Apply still labeled "Bắt đầu dọn".

## Emotional Journey
Anxiety peaks: opening adv block (8 cards → ~35 controls); landing on 2000-row review; both unmitigated. The Apply confirm modal is the best-handled moment (plain recap + undo reassurance + "Không file nào bị xoá"). Running screen lacks reassurance; disabled Apply's explanation sits far from the button.

## Personas
- Jordan (first-timer, key persona): breaks at the 8-equal-preset wall (no recommendation); "Dọn sâu tới đâu?" arrives early with forward reference; 2000 rows + 8 unexplained tags; grey Apply without nearby explanation.
- Alex (power user): can't bulk-untick by filter; toast-only rescan; no saved profiles; granularity slider appears only with AUTO_PROJECT layer.
- Sam (a11y): row checkboxes lack aria-label (×2000); confirm modal lacks role="dialog"/focus trap/Esc; toasts lack aria-live; segmented controls lack aria-pressed.

## What's Working
1. Best-in-class plain-Vietnamese UX copy with real examples throughout i18n.js.
2. Safety architecture is *displayed* at every risk point (green reassurance, undo as primary post-run action).
3. Technical discipline serving UX: hand-tuned contrast, virtual list, two-layer i18n incl. on-disk folder names.

## Priority Issues
- [P0] Preset wall: 8 equal cards, none preselected, no "Nên dùng" badge. Fix: use S.analytics to preselect + badge 1 preset, show top 3 + "Xem 5 kiểu khác". (distill/onboard)
- [P0] Adv mega-form: #adv-block opens 7 sections (~35 controls) at once. Fix: accordions closed by default, headers show current-value summary. (distill)
- [P1] Step 4 lacks bulk ops + legend: filters are view-only; plainSummary buried. Fix: hero summary card with clickable counts, "untick all in filter", tag tooltips. (distill/clarify)
- [P1] Stale-plan is toast-only. Fix: sticky banner with [Quét lại ngay] button. (harden/clarify)
- [P2] Bundle: screen-2 density (fold details), ReportOnly Apply label, a11y basics (aria-label rows, dialog semantics, aria-live toasts). (clarify/harden)

## Minor Observations
"Bản 1.3" (HTML fallback) vs "Bản 2.0" (i18n); hardlink label; raw error strings; granularity slider hidden dependency.

## Questions to Consider
1. If undo is truly 100% trustworthy, why make users "review" 2000 rows? Step 4 could default to one sentence + button.
2. Does step 2 need to be a *step*, or should its verdict feed straight into step 3's recommendation?
3. Should "Dọn cả một ổ đĩa" be pitched to basic users on the first screen?
